# Sage 300 2023 — release notes, integration-relevant extract

For exact Sage wording and the full fixed-issue / known-issues lists, see Sage's official 2023 Release Notes and
Technical Information pages (URLs in `../upgrades/upgrade-guide.md` § 2); the verbatim pages are not bundled.
Schema facts below are cross-checked against the bundled dictionaries (`../dictionary/6.0A` → `7.0A`). 2023 is the release where Sage's **security overhaul** landed
(GA, PU2, PU3); the mechanics are in the Enhanced Security PDF, summarised in `../upgrades/upgrade-guide.md` § 4.

## 2. Changes by release — what matters to consultants and integrations

### 2023.0 (GA, ~August 2022)
- **Security**: one "require complex passwords" option (lower, upper, digit, special); back-end "system and databases" hardening (W2, W3).
- **CRM**: CRM Server Name up to 60 chars; CORS default changed (W6); customer contact-name changes can push to CRM.
- Web screens: IC Assemblies/Disassemblies, Bills of Material, Lot Recalls/Releases, Serial Numbers; PJC Account Sets, Charges, Revise Estimates, Update Retainage; setup reports for AP/AR/GL/TX/BK/IC/OE/PO/PJC; keyboard navigation.
- Start menu split into Sage 300 / Admin Utilities / Support Utilities, with Data Activation, License Manager and Current Users runnable without opening Sage 300 (W4).

### PU1 (December 2022)
- **User Activity Report** (login/logout/screen open/close/eviction per company) — enabled per system database via the new **"Enable User Activity Logs"** checkbox in Database Setup; admin-only.
- **1099 / Aatrix**: 1099-INT, -MISC, -NEC supported; more 1099-INT amount types; **A/P Electronic Filing screen removed**; A/P 1099 Filing screen gains Process/History buttons and Title/Transfer Agent fields. Any custom 1099 process built on the old screen needs rework.
- Web screens: PJC Revise Estimates posting; IC Bills of Material and Assemblies.

### PU2 / PU3 (2023)
- **"Sage 300 is more secure"** — the enforced-security release: multi-step install, system setup changes, third-party impact (W1). This is where per-user SQL logins and the Vault/Store databases arrive (see the upgrade guide).

### PU4 — Lanpak / Current Users handling improved; Singapore Tax Report e-file. Workstation Setup changed (W7).
### PU5 — **AP: five 1099 vendor fields** (First Name, Last Name, FATCA, Second TIN Notice, Tax Withholding State) + Form 1099-DIV. Schema: appended `APVEN` columns; not in the 7.0A export (GA), present from the 7.2A dictionary.
### PU6 — fixes only.
### PU7 — **Sage HR Integration v8.0** supported: install/activate, `wssetup.cmd` per workstation, Payroll 8.0 with tax update "C".
### PU8 — fixes only.
### PU9 — AP: T5018 (CPRS) forms for tax year 2024.
### PU10 — fixes only (last 2023 PU).

## 3. Schema verdict

**Additive.** 6.0A → 7.0A (2023.0 export) adds tables (multi-contacts `ARCUSC`/`APVENC`, TS/TW/TM tax add-ons) and
columns (`OEORDD.REQUESDATE`, `ICITEM.TARIFFCODE/SEASONAL/DEFBOMNO/PREVENDTY`, `ICILOC.LEADTIME/QTYMINREQ`,
`ARCUS.BRN/CATEGORY`, `APVEN.BRN`); the `MF*` manufacturing tables in 6.0A are a separate add-on. The PU5 1099 vendor
columns are appended later. Core keys and existing columns unchanged. The 2023 risk is **authentication**, not schema:
after PU2/PU3 an integration's Sage user is backed by a SQL login subject to the new policy.
