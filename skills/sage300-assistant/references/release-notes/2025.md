## 2. Changes by release — what matters to consultants and integrations

### 2025.0 (GA, ~August 2024)
- **Payroll web screens moved to the Tax Update installer** (W1) — the root of the 2026 "reinstall the tax update with Payroll Web Screens ticked" warning.
- **Sage HR Integration v8.0** required (W3).
- **eInvoicing (Malaysia, LHDN)**: AR/OE invoices, credit and debit notes to the government; separate installation, needs 2024 PU2+. Schema: the `EI*` tables ship with that add-on, not the core (they appear in the 7.3A export, not 7.2A).
- **GL**: double-click an account in Chart of Accounts to list its transactions; GL transactions export to Excel (web and desktop).
- Information Center reachable from web screens; Sage Intelligence updated (details in TI).

### PU1 (~Nov 2024)
- AP: T5018 (CPRS) forms for tax year 2024. W2 applies.

### PU2
- HR Integration sync enhanced; encrypted activity logging. Clients on **2023 with Workstation Setup** need extra KB steps for HR Integration.
- Web screens: favourites list; general performance work.
- **Bank Feeds re-platformed**: onboarding with a Sage ID; existing feeds migrated behind the scenes. Bank-feed users should expect a re-authorisation step.
- Sage Intelligence: Auto-Bulk Import, Report Scheduling (daily/weekly).

### PU3
- US Payroll: Accrual Limit feature.

### PU4
- New Information Center icon (English content only).

### PU5 (= 2026 PU2 back-port)
- **Bank Services: OFX 2.x (XML) statements** (#8010617262).
- **Web API: IC Manufacturers' Item end-point.**
- GL: warning when reversing a subledger batch.
- Sage Help Agent; Information Center opens before a company; Sage Intelligence workstation-level scheduling and network-share metadata repositories.

### PU6 (= 2026 PU3 back-port)
- **OE "Update Customer Number" security right** — changing the customer on OE Order / Shipment / Credit-Debit Note after lines exist now errors unless the right is granted (Security Groups → Order Entry). Check the Sage user any integration logs in as. Classic and web.
- Web screens: custom Crystal report parameters via `ReportAllowCustomParameters=true` in web.config (slows the Export dialog).
- Workstation Setup changed (W4).

## 3. Schema verdict

**Additive, with one type widening.** 7.1A (2024.0 export) → 7.2A (2025.1 export): no new tables; `APVEN` gains
FATCA, FIRSTNAME, LASTNAME, SECONDTIN, TAXWHSTTE (**not a 2025 change**: Sage shipped these in 2023 PU5 / 2024 PU1; the 7.1A export is 2024.0 and
predates them, so they first *appear* in the 7.2A export while any 2023 PU5+ / 2024 PU1+ database already has them); CPEMPL/UPEMPL gain EMPLERDENT, PAYERDENT, WLCOUNTY; CT T4/R1
tables gain pension fields. **Payroll `CHECKNUM` / `TRANSNUM` widened from BCD*5.0 to BCD*8.0** (DECIMAL(9,0) →
DECIMAL(15,0)) on CP/UP CHKH, CHKL, CHKS, ACCO, ETRN and MC* tables — payroll views or integrations that declare these as
INT/DECIMAL(9,0) must be widened. Core OE/IC/AR/PO/GL tables unchanged.
