## 1. Upgrade warnings and requirements

| # | Applies if the client... | Do this | Source |
|---|---|---|---|
| W1 | uses **Web Screens** (with or without Payroll) and comes from **any version before 2025** | Uninstall the old Web Screens **before** installing 2026: Control Panel → Programs and Features → Sage 300 → Change → Modify → Next → untick *Web Screens* → finish with defaults. Then tick *Web Screens* in the 2026 installer. | RN 2026.0; KB 250808163127480 |
| W2 | uses **Payroll Web Screens** and comes from **2023 or 2024** | After the upgrade, re-install the latest Payroll Tax Update with the *Payroll Web Screens* option checked; otherwise web screens error or payroll web screens are invisible. | RN 2026.0 |
| W3 | uses **Global Search** and plans a Windows *Repair* of Sage 300 | Back up and uninstall Global Search first (Modify option); after the Repair reinstall it via Modify, then open Database Setup and edit-and-save any company (no changes) so Global Search works again. | RN 2026.0 |
| W4 | uses **Sage HR Integration** | HR Integration **8.1** required — only compatible with 2026+; needs Payroll Tax Update Q3 2025 (8.0E, 18 Sep 2025) or later. | RN 2026.0 |
| W5 | is on any PU below 3 and applies PU3 | **PU3 changes Workstation Setup** → reinstall on every workstation. | TI |
| — | any | Upgrade floor **5.6 or later**; all modules to 2026 at once; .NET 4.8 and MSXML 6.0 installed by the installer. After any PU: re-run Database Setup for the Portal DB (web screens), reinstall the CRM integration + Synchronization Component, clear browser caches. | TI |

A 2025 → 2026 move triggers none of W1/W2; a 2023/2024 → 2026 move with web screens triggers W1 and, with payroll, W2.

## 2. Changes by release — what matters to consultants and integrations

### 2026.0 (GA, September 2025)
- **Currencies (system DB)**: BDT added to the default currency set; obsolete pre-Euro currencies removed from the defaults. Applies to *newly activated* system databases — existing databases keep their currency tables.
- **AR / AP**: invoice-entry finders search by customer / vendor name; AR Customer List exports directly from the screen.
- **GL**: Optional Fields for posted transactions can be exported from GL Transaction History.
- **IC**: Day End Processing screen shows *Last Processed By*. Schema: the new `ICOPT.ULASTDEP` column (String*8) — the only IC schema change in 2026.
- **System Manager**: RegAcc.log records failed exe registrations.
- Web screens: PJC setup screens — Contract Structures, Segment Codes, Miscellaneous Expenses, Options, Optional Fields, Projects, Overhead Expenses, Subcontractors, Charges.
- Fixes worth knowing (TI): PO Create-PO-from-Requisition finder performance; PJC Contract Maintenance load performance; Sales Analysis scheduled AUTO mode; Bank Feeds currency download.

### PU1
- New Information Center icon (English content only). Web screens: PJC Categories, Employees, G/L Integration; Bank Transaction History Inquiry and Bank Reverse Transactions support Payroll.
- Fixes (TI): concurrent AP web report printing; CRM quote→order optional-field mapping on detail lines (#8010507929).

### PU2
- **Bank Services: OFX 2.x (XML) statement files** (#8010617262).
- **Web API: IC Manufacturers' Item end-point.**
- **GL: warning when reversing a subledger batch** (user can still proceed).
- Sage Help Agent; Workstation Setup progress meter; Information Center opens before a company; Sage Intelligence workstation-level scheduling and network-share metadata repositories.
- Fixes (TI): **SQL login lock-out when `UserAuthenticatedListOfCompanies` is enabled** (#8010606612); RVSpy/DBSpy on web screens; email password > 48 chars; IC Transfers web UOM-change quantity error (#8010769330); AR web invoice item tax class; OE Credit/Debit Note extended cost with Pricing Unit default; T5018 special-character warning.

### PU3 (September 2026)
- **OE "Update Customer Number" security right** (Security Groups → Order Entry). Without it, changing the customer number on OE Order Entry, Shipment Entry or Credit/Debit Note Entry after detail lines exist raises an error (delete all lines first, or grant the right). Classic and web. **Integration impact**: any process or user that creates the header, adds lines and then re-keys the customer needs this right — check the Sage user an integration logs in as.
- **Import/export no longer uses the Microsoft Access Database Engine 2016**; Excel import/export now uses the web-screens engine (#8010649072, #8010687490). Retest scheduled imports and macros that relied on the ACE driver.
- Web screens: custom Crystal report parameters via `ReportAllowCustomParameters=true` in web.config (slows the Export dialog for all reports).
- PJC Transaction History drills down to Payroll Check Inquiry (web). Workstation Setup changed (W5).
- Fixes (TI): GL provisional posting with transaction optional fields (#8010897576); Bank Reconciliation web Cleared Amount decimals; custom desktop folder icons/rights; CRM multi-CC email.

## 3. Schema verdict

**Additive only.** 7.2A (2025.1) → 7.3A (2026.0): 44 tables added (`EI*`/`EC*` eInvoicing add-ons — Malaysia and
Singapore — not mentioned in these release notes; payroll year-end `CTT4PH`/`CTR1PH`/`UTW2PH` etc.), a handful of
payroll/1099 columns added, `UTW2PD.REPORTID1/2` widened 16 → 20 chars. No table or column removed;
OEORDH/OEORDD/OESHIH/OEINVH/ICITEM/ICILOC/ARCUS/APVEN/POPORH1/GLAMF unchanged. Views and integrations on the core
OE/IC/AR/AP/PO/GL tables run unchanged.
