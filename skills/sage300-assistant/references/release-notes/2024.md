## 2. Changes by release — what matters to consultants and integrations

### 2024.0 (GA, ~August 2023)
- **Web API**: CP Employee, UP Employee and **IC Item Location details** end-points added.
- **Global Search** introduced (W2).
- **Financial Reporter for the Web** introduced; **Sage Intelligence Report Cloud (SIRC) deprecated**.
- Web screens: PJC Equipment Usage, Adjustments, Timecards, Transaction History (+ report); job-related documents on all PO web screens (Requisition → Credit/Debit Note, Copy POs, reports, inquiries).
- Direct API bank feeds via Sage Service Fabric (e.g. Bank of America CashPro).
- Singapore: IRAS ASR Tier 2 GST F5/F8 direct submission (web screens, TS module).

### PU1 (~Nov 2023)
- **AP: five 1099 fields on the vendor** — First Name, Last Name, FATCA, Second TIN Notice, Tax Withholding State (also in Inquiry Reporting); Form 1099-DIV supported. Schema: `APVEN.FIRSTNAME / LASTNAME / FATCA / SECONDTIN / TAXWHSTTE` — **appended** columns. **Attribution rule:** the *feature* shipped in 2023 PU5 and 2024 PU1, so any 2023 PU5+ or 2024 PU1+ database has these columns; the bundled *dictionaries* are point-in-time exports (7.1A = 2024.0) and first show them in 7.2A. Say "shipped in 2023 PU5 / 2024 PU1", not "added in 2024" or "added in 2025".
- Web screens: PJC Budget Maintenance. Sage Support Resource Centre in menus. W1 applies.

### PU2
- **Subclassing supported in web screens and the Web API** (relevant to customisations). Translation Package included in the Desktop SDK.

### PU3
- eInvoicing (Malaysia) for AR invoices/credit/debit notes — separate install, needs PU2+. HR Integration v8.0 (W3).

### PU4
- eInvoicing extended to OE and AP self-billed documents, and inbound documents into AP (separate install, needs PU4+).

### PU5 — AP: T5018 (CPRS) forms for tax year 2024.
### PU6 — fixes only.
### PU7 — US Payroll: Accrual Limit feature.
### PU8 — New Information Center icon (English content only).

### PU9 (= 2026 PU2 back-port)
- **Bank Services: OFX 2.x (XML) statements**; **Web API: IC Manufacturers' Item end-point**; GL warning when reversing a subledger batch; Sage Help Agent; Information Center before company open. Workstation Setup changed (W4).

## 3. Schema verdict

**Additive.** 7.0A (2023) → 7.1A (2024.0 export): two new tables (`ASAUDT`, `TSEFAUD`); no columns added or removed;
enum-list edits only (`APCLX.CATEGORY` gains 1099-INT/OID amount codes; `UPCOBK.BANKFORMAT` drops an empty value).
The PU1 1099 vendor columns and later payroll columns land in the 7.2A dictionary. Core OE/IC/AR/PO/GL tables unchanged.
What actually bites on a move to 2024 is not schema but **Enhanced Security** (see the upgrade guide): integration users
need "Password Never Expires", and Sage-owned DSNs move to ODBC Driver 18 with certificate validation.
