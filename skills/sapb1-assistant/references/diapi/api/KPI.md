# KPI (Object)

A KPI set is a parameter set that you can define or modify parameters for dashboards. Source table: OKPI.

## Properties (5)
- `Public Property KPI_ItemLines() As KPI_ItemLines` [R] The line entries of a parameter set.
- `Public Property KPICode() As String` [R/W] The code of the parameter set that you are going to define. Field name: KpsCode. Length: 15 characters.
- `Public Property KPIName() As String` [R/W] The name of the parameter set that you are going to define. Field name: KpsName. Length: 100 characters.
- `Public Property KPIType() As KPITypeEnum` [R/W] The type for the parameter set. Field name: KpsType.
- `Public Property NumberOfColumns() As Long` [R/W] The number of columns in the parameter set. Field name: FieldsNum.
