# DocumentChangeMenuName (Object)

Represents the user-defined menu name for a specific document type/document subtype. For example, the menu for sales order documents is Sales Orders. The name can be changed to Orders (or any other string) with this object. Source table: The ONNM table, whose child table NNM1 is used for the SeriesService object, contains the field DocAlias, which is stored in the ChangedMenuName property.

**Remarks:** Use this object with the GetDocumentChangedMenuName and ChangeDocumentMenuName methods of the SeriesService.

## Properties (3)
- `Public Property ChangedMenuName() As String` [R/W] The user-defined menu name for the document type/document subtype specified in the Document and DocumentSubType properties. Field name: DocAlias Length: 20 characters
- `Public Property Document() As String` [R/W] The document type.
- `Public Property DocumentSubType() As String` [R/W] The document subtype.
