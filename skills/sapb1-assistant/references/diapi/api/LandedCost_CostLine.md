# LandedCost_CostLine (Object)

The LandedCost_CostLine object enables you to allocate landed costs to the various items according to specific criteria, for example volume, weight, or quantity. Source table: IPF2.

**Remarks:** To access the form in the application, choose Purchasing A/P --> Landed Costs, and choose the Costs tab.

## Properties (14)
- `Public Property AllocationBy() As LandedCostAllocationByEnum` [R/W] Allocation method as defined in the Landed Costs – Setup window for each landed cost. Field name: OhType.
- `Public Property amount() As Double` [R/W] Amount of expenditures to be distributed on lines. Field name: CostSum.
  - remarks: When the landed costs document is based on another landed costs document, this field represents the final invoice amount. That is, the amount difference between the base and the final amount is calculated and posted.
- `Public Property AmountFC() As Double` [R/W] Amount of expenditures to be distributed on lines in foreign currency. Field name: CostSumFC.
- `Public Property Broker() As String` [R/W] property Broker
- `Public Property BrokerName() As String` [R/W] property BrokerName
- `Public Property CostCategory() As LandedCostCostCategoryEnum` [R/W] property CostCategory
- `Public Property CostType() As LCCostTypeEnum` [R/W] The landed costs type. Field name: CostType.
- `Public Property DocEntry() As Long` [R] The internal ID of the landed costs. Field name: DocEntry.
- `Public Property Factor() As Double` [R] Percentage rate of each landed cost out of the total FOB costs of the shipment. This factor can help you determine the shipment efficiency in comparison to other shipments or certain standards. Field name: Factor.
- `Public Property IncludeForCustoms() As BoYesNoEnum` [R/W] Specify whether the associated landed cost is allowed for customs calculation and should thus be included in the actual customs duty calculation and allocation. Field name: InCustCalc.
- `Public Property LandedCostCode() As String` [R/W] The code of the landed cost. This is a foreign key to the LandedCostsCodes object. Field name: AlcCode. Length: 2 characters.
- `Public Property OpenAmount() As Double` [R] property OpenAmount
- `Public Property OpenAmountFC() As Double` [R] property OpenAmountFC
- `Public Property UserFields() As Fields` [R] property User Fields
