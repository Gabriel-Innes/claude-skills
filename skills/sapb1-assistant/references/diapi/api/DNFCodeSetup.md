# DNFCodeSetup (Object)

Represents a DNF code that can be assigned to an item. Source table: ODNF Mandatory properties: DNFCode, NCMCode

**Remarks:** Relevant for Brazil only.

## Properties (5)
- `Public Property AbsEntry() As Long` [R] The key for a specific DNF code. Field name: AbsEntry
- `Public Property DNFCode() As String` [R/W] The DNF code. Field name: DNFCode
  - remarks: Cannot be blank and must be unique among the DNF codes associated with the NCM code in the NCMCode property.
- `Public Property Factor() As Double` [R/W] The factor for the DNF code. Field name: DNFFactor
- `Public Property NCMCode() As Long` [R/W] The key to the NCM code to which the DNF code is associated. Field name: NCMEntry
  - remarks: An NCMCode with this key must exist in the ONCM table.
- `Public Property UoM() As String` [R/W] The UoM for the DNF code. Field name: DNFUoM
