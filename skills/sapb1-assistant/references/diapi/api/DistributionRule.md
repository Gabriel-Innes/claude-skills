# DistributionRule (Object)

Represents a distribution rule for spreading a specific expense, account, journal entry, or other entity among profit centers. Source table: OOCR Mandatory properties: FactorCode, TotalFactor

## Properties (9)
- `Public Property Active() As BoYesNoEnum` [R/W] Specify whether the distribution rule is active. Field name: Active.
  - remarks: In SAP Business One, you can use only active distribution rules.
- `Public Property Direct() As String` [R/W] Indicates whether the allocation of amounts is done directly or indirectly. Field name: Direct
- `Public Property DistributionRuleLines() As DistributionRuleLines` [R] The set of profit centers to which to assign costs and revenues that have been tied to this distribution rule.
  - remarks: There cannot be more than one DistributionRuleLine objects with the same profit center assigned to the same distribution rule. All profit centers assigned to a distribution rule must have the same dimension as the distribution rule (InWhichDimension property).
- `Public Property FactorCode() As String` [R/W] The key for a specific distribution rule. Field name: OcrCode
- `Public Property FactorDescription() As String` [R/W] A description for a specific distribution rule. Field name: OcrName
- `Public Property InWhichDimension() As Long` [R/W] The dimension in which this distribution rule is located. Field name: DimCode This is a foreign key to the Dimension object.
  - remarks: The dimension must be active.
- `Public Property IsFixedAmount() As BoYesNoEnum` [R/W] property IsFixedAmount
- `Public Property TotalFactor() As Double` [R/W] A number that represents 100 percent of the amount to be distributed. For example, if TotalFactor is 80, and the distribution contained profit center A at 20 and profit center B at 60, then profit center A would be allocated 25 percent and profit center B would be allocated 75 percent. Field name: OcrTotal
- `Public Property UserFields() As Fields` [R] Returns the UserFields object.
