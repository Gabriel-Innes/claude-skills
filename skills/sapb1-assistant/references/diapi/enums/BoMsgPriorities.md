# BoMsgPriorities (Enumeration)

Defines a priority flag to a message or a contact activity.

| Member | Value | Description |
|---|---|---|
| pr_Low | 0 | Low priority. |
| pr_Normal | 1 | Normal priority. |
| pr_High | 2 | High priority. |
