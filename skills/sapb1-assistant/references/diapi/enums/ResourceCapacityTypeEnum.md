# ResourceCapacityTypeEnum (Enumeration)

The resource capacity types.

| Member | Value | Description |
|---|---|---|
| rctInternal | 0 | The internal resource capacities. You can manually update the Internal capacity data. |
| rctOrdered | 1 | Ordered capacity displays the total quantity of the Qty (Inventory UoM) grid line field for the noninventory item linked to this resource. |
| rctCommitted | 2 | The resource capacities that are committed to production orders. |
| rctConsumed | 3 | The resource capacities that are consumed by production orders. |
