# SubsequentAcquisitionProRataTypeEnum (Enumeration)

Specify one of the PR Temporis Type to determine the depreciation start date.

| Member | Value | Description |
|---|---|---|
| saprtExactlyDailyBase | 0 | Recalculates the asset depreciation from the very day when the subsequent acquisition takes place. |
| saprtFirstDayOfCurrentPeriod | 1 | Recalculates the asset depreciation from the first day of the posting period within which the subsequent acquisition takes place. |
| saprtFirstDayOfNextPeriod | 2 | Recalculates the asset depreciation from the first day of the posting period that follows the period of subsequent acquisition. |
