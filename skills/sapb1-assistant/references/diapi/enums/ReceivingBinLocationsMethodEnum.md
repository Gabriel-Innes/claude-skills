# ReceivingBinLocationsMethodEnum (Enumeration)

The method by which items are received at receiving bin locations.

| Member | Value | Description |
|---|---|---|
| rblmBinLocationCodeOrder | 0 | Bin Location Code Order - Receives items at receiving bin locations according to the alphanumeric order of the bin location codes. |
| rblmAlternativeSortCodeOrder | 1 | Alternative Sort Code Order - Receives items at receiving bin locations according to the alphanumeric order of the receiving bin locations' alternative sort codes. |
