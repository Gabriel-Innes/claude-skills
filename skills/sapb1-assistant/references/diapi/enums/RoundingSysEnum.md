# RoundingSysEnum (Enumeration)

Methods for rounding payment amounts in the Currencies object.

| Member | Value | Description |
|---|---|---|
| rsNoRounding | 0 | No rounding. |
| rsRoundToTenHundredth | 1 | Round to ten hundredth. |
| rsRoundToOne | 2 | Round to one. |
| rsRoundToTen | 3 | Round to ten. |
| rsRoundToFiveHundredth | 4 | Round to five hundredth. |
