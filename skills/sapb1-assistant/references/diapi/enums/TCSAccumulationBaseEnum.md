# TCSAccumulationBaseEnum (Enumeration)

TCS Accumulation Base in the Financial Year Master - Setup window.

| Member | Value | Description |
|---|---|---|
| tcsAccumulationOnInvoice | 0 | Accumulate the TCS amount based on invoices. |
| tcsAccumulationOnPayment | 1 | Accumulate the TCS amount based on incoming payments. |
