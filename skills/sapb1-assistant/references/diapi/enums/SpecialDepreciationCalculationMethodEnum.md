# SpecialDepreciationCalculationMethodEnum (Enumeration)

The calculation method of special depreciation.

| Member | Value | Description |
|---|---|---|
| spcmAdditional | 0 | The system calculates the depreciation in addition to the standard depreciation amount. |
| spcmAlternative | 1 | The system calculates the depreciation for a second depreciation type in parallel. |
