# SortOrderEnum (Enumeration)

Sort order of columns in a Choose from List form.

| Member | Value | Description |
|---|---|---|
| soAscending | 0 | Ascending order (the left most column displays the the first field). |
| soDescending | 1 | Descending order (the left most column displays the the last field). |
