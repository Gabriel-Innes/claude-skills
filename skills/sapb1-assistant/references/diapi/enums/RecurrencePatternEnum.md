# RecurrencePatternEnum (Enumeration)

Specifies the frequency of the recurring activity.

| Member | Value | Description |
|---|---|---|
| rpNone | 0 | Non-recurring activity |
| rpDaily | 1 | Daily |
| rpWeekly | 2 | Weekly |
| rpMonthly | 3 | Monthly |
| rpAnnually | 4 | Annually |
