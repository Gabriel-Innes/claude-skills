# RepeatOptionEnum (Enumeration)

Specifies the date on which the recurring activity is to take place.

| Member | Value | Description |
|---|---|---|
| roByDate | 0 | The date you have specified for Start Time. |
| roByWeekDay | 1 | The day of the week you have specified for Start Time. |
