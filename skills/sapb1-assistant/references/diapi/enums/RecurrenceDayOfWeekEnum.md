# RecurrenceDayOfWeekEnum (Enumeration)

For monthly activities, specify the days when the activity recurs. You can specify multiple days.

| Member | Value | Description |
|---|---|---|
| rdowDay | 0 | Day |
| rdowWeekDay | 1 | Week day |
| rdowWeekendDay | 2 | Weekend |
| rdowSun | 3 | Sunday |
| rdowMon | 4 | Monday |
| rdowTue | 5 | Tuesday |
| rdowWed | 6 | Wednesday |
| rdowThu | 7 | Thursday |
| rdowFri | 8 | Friday |
| rdowSat | 9 | Saturday |
