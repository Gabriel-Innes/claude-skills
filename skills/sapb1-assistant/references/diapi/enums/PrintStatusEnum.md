# PrintStatusEnum (Enumeration)

Print statuses of documents.

| Member | Value | Description |
|---|---|---|
| psNo | 0 | The document was not printed. |
| psYes | 1 | The document was printed. |
| psAmended | 2 | The document was amended. |
