# BoCorInvItemStatus (Enumeration)

Specifies status of the correction invoice.

| Member | Value | Description |
|---|---|---|
| ciis_Was | 0 | A correction invoice was created. |
| ciis_ShouldBe | 1 | A correction invoice should be created. |
