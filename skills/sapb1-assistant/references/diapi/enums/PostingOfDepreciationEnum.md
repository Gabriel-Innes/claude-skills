# PostingOfDepreciationEnum (Enumeration)

The depreciation posting methods.

| Member | Value | Description |
|---|---|---|
| podDirectPosting | 0 | The system posts the asset depreciation directly in the asset balance sheet account. |
| podIndirectPosting | 1 | The system posts the asset depreciation in the accumulated depreciation accounts and transfers the depreciation to the asset balance sheet account only when the asset is retired. |
