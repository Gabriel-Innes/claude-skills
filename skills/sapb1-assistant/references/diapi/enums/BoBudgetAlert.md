# BoBudgetAlert (Enumeration)

Specifies the alert options in case of deviation from budget.

| Member | Value | Description |
|---|---|---|
| ba_AnnualAlert | 0 | Annual budget alert. |
| ba_MonthlyAlert | 1 | Mounthly budget alert. |
