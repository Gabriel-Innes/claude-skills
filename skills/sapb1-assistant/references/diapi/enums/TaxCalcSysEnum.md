# TaxCalcSysEnum (Enumeration)

Methods for tax calculation for the Tax Calculation Engine.

| Member | Value | Description |
|---|---|---|
| PreconfiguredFormulaWithJurisdictionSupport | 0 | Preconfigured formula with jurisdiction support (e.g. US tax system). |
| UserDefinedFormula | 1 | User defined formula (e.g. BR & IN). |
| PreconfiguredFormula | 2 | Preconfigured formula (e.g. EU tax system). |
