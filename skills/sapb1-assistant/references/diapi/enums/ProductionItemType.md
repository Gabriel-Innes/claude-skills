# ProductionItemType (Enumeration)

The type of the production item.

| Member | Value | Description |
|---|---|---|
| pit_Item | 0 | Specify a desired item. |
| pit_Resource | 1 | Specify a desired resource. |
| pit_Text | 2 | Add text in the line. |
