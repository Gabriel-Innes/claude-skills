# BoCurrencySources (Enumeration)

| Member | Value | Description |

| bocs_LocalCurrency | 0 | Local currency. |
| bocs_SystemCurrency | 1 | System currency. |
| bocs_BPCurrency | 2 | Business partner currency. |
