# RetirementProRataTypeEnum (Enumeration)

Specify one of the PR Temporis Type to determine the depreciation end date.

| Member | Value | Description |
|---|---|---|
| rprtExactlyDailyBase | 0 | Calculates the asset depreciation till the very day of retirement. |
| rprtLastDayOfPriorPeriod | 1 | Calculates the asset depreciation till the last day of the posting period prior to the period of retirement. |
| rprtLastDayOfCurrentPeriod | 2 | Calculates the asset depreciation till the last day of the posting period in which the retirement takes place. |
