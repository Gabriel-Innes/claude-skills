# BoSvcCallPriorities (Enumeration)

Specifies the service call priority.

| Member | Value | Description |
|---|---|---|
| scp_Low | 0 | Low priority. |
| scp_Medium | 1 | Medium priority. |
| scp_High | 2 | High priority. |
