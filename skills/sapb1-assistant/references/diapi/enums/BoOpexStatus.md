# BoOpexStatus (Enumeration)

Specifies the payment status for each row in the OPEX table (PaymentRunExport object).

| Member | Value | Description |
|---|---|---|
| bos_Open | 0 | The payment is open. |
| bos_Close | 1 | The payment is closed. |
