# StraightLinePeriodControlDepreciationPeriodsEnum (Enumeration)

The depreciation period of the straight line period control depreciation method.

| Member | Value | Description |
|---|---|---|
| slpcdpStandard | 0 | Enables you to specify a factor for depreciation calculation that can be applied to all periods of an asset's useful life. |
| slpcdpIndividual | 1 | Enables you to specify multiple factors for depreciation calculation that can be applied to different periods of an asset's useful life. |
