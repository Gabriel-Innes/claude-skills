## 3. Behaviour changes (flagged `[BEHAVIOUR CHANGE]` by Sage)

- **Distribution**: Inter-site receipt quantity does not refresh after change receipt (X3-307366) - You can only increase the quantity on an existing inter-site receipt if the full delivered quantity was received. Elements: AML 194, TRT SUBPTHB
- **Finance**: Bank statement import (POR) in a single-legislation folder (X3-312342) - You can use the Bank file (Portugal) field for Portuguese and Spanish legislations. Elements: ADP PORRBK, ATB BANK, TRT SUBBAN, ACV KPS, AMK BAN2
- **Manufacturing**: Weighing module: Full touch mode and selecting rows in a table (X3-314241) - When using the Weighing module in full touch mode, you can scroll the list and select the row on a touch screen.
- **Manufacturing**: If the remaining quantity to allocate is less than 1, it does not display on the Lot selection (X3-313249) - Weighing scale: The remaining quantity to allocate displays on the Lot selection screen.
- **Manufacturing**: Weighing scale protocol does not manage old MTSICS protocol (X3-310219) - In the ini file, you can use a new parameter to employ "full control" when the scale is managed by the interface.
